# A 方案 UI 全面重构 · M0–M6 验收记录

设计依据：用户 2026-11-15 选定的 A 方案提示词和用户参考图、无边框窗口视频。仓库 UI-design、UI-design-plan 不作为设计参考。

产品定位：单一 Minecraft 启动器。主页的主要流程是选择实例、确认账号、启动 Minecraft。保留原图标、现有业务服务和用户数据兼容性。

- M1：14 项新外壳检查通过，覆盖 216/64 DIP、上下导航、账号入口、主题与键盘焦点。
- M2：18 项检查通过，覆盖选择与启动分离、实际启动委托、最近记录、筛选、首次使用与 900/1366/1920 宽度。缩小窗口误进入详情已修复并复验。

### M3–M5 已完成

- M3：71 项实例管理检查通过，验证批量模组操作、快照恢复、试装副本、整合包更新及设置同步。
- M4：103 项安装/资源检查和 31 项联机检查通过。资源列表的高度断言已按分类侧栏和两行筛选的新布局更新，继续校验有效结果高度与位置。
- M5：49 项账号、角色预览及更新流程检查通过；全页面深浅双主题、快速切页、紧凑窗口和减少动画的检查通过。视觉复查发现的字符串按钮前景继承问题已修复，补充实际文本前景检查后复验。

使用 `packaging/check-ui-a.ps1 -Stage M0` 至 `-Stage M6` 单独运行，也可用 `-Stage All`。脚本输出每阶段日志与截图到 D 盘 scratch 目录。M6 脚本检查当前 Windows 原生窗口；最终发布还需按 release-policy.md 验证 EXE、签名更新清单及远端资产。

## 最终布局与组件

- 应用外壳：52 DIP 标题栏，左侧 216 DIP 导航，可收为 64 DIP；主页/实例/联机/资源在上方，下载/设置在下方。
- 主页：当前实例名称、版本、账号、实例选择与启动组成一个连续区域；下方最多四条最近实例，运行环境按需展开。
- 实例：搜索/分组/收藏工具栏，虚拟化列表，明确的行内启动与管理按钮，右侧按需展示当前实例详情。
- 实例详情：左侧局部导航，右侧管理内容；高级启动参数折叠，保存操作固定在内容底部。
- 资源：左侧分类，右侧搜索筛选与结果；详细内容展开后分类列收起。
- 联机：连接设置与启动目标分区，小窗口自动上下排列。
- 设置：局部分类导航与表单区。角色：预览与编辑分栏。任务：固定筛选工具区与可滚动状态记录。
- 浅色：#F4F5FA / #FFFFFF / #202131 / #6554D9。深色：#14151B / #1E2029 / #F1F2F7 / #9B8CFF。
- 组件资源在 Styles/Tokens.axaml 与 Styles/Workbench.axaml；语义主题在 Appearance/DesktopThemes.cs。按钮悬停120ms、按下85ms、导航170ms、切页200ms、对话框170ms，减少动画时停用位移和缩放。

### M6 本机验收

- Windows 原生窗口 20 项通过：标题栏与按钮命中、边缘缩放命中、双击最大化、还原、最小化、900/1366/1920 窗口客户区和 1.25/1.5/2 倍渲染。
- 实际检查深浅主题的主要页面与紧凑截图，修复纯文字按钮前景继承；角色页不再对隐藏导航项显示指示条，实例详情侧板随实例数量更新。
- 其他待测环境：Windows 10、真实系统 125/150/200% 缩放、多显示器人工拖动/八向缩放与 Snap 悬停面板、真实远端联机、真实模组客户端。倍数渲染截图不等于这些环境实测。
- 本批启动与联机流程回归使用隔离服务夹具；真实原版启动验收可参考上一版本 M9 记录，但不计入本批通过数量。
- 发布前将再校验裁剪后的实际程序集与单文件启动；签名更新清单、远端哈希与 Release 链接在发布记录中补录。

- 原生窄窗口发现的导航旧占位已修复：列宽跟随侧栏实际过渡宽度；新增中间帧、内容跟随、结束宽度及左边界检查，20 项原生验收通过。
