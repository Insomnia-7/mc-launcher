## 改动依据

- 搜索结果由虚拟列表显示，恢复Auto竖向滚动条。原生滚轮在搜索任务等待时仍能移动已有结果。搜索进度放在列表外独立行，避免遮住资源条及滚动区域。
- 原EnsureLoadedAsync每次进入都会检索。现在复用当前检索结果与滚动位置，手动搜索仍刷新；首次工作在页面600ms转场完成后开始，不在导航命令中同步处理。
- 用户先观看独立卡片演示，再选择淡出和淡入各300ms。正式动画使用动画优先级，不覆盖卡片绑定和禁用样式；快速切页最多持有相邻两页，旧页在新卡片入场前脱离渲染树。缩放、关闭动画、卸载和最小化会结束转场并恢复可见状态。
- API Key接入是可选构建输入，源码不含用户提供的值。官方搜索接口实际返回403 missing or invalid；本批不公开该凭据。Upload API和搜索API区别、申请步骤及填写说明见curseforge-project-api.md。

## 实测边界

当前电脑Windows11、100%缩放；隔离实例/账号与资源夹具。新增检查包含原生窗口输入；远端CurseForge测试仅用于确认认证结果，没有读取或修改作者私有项目。没有取得可用搜索Key，因此不能声称CurseForge搜索已恢复。其他真实DPI、Windows10、IME组合与人工窗口手势继续待测，Java/Rust真实游戏与远程联机待测范围延续上一版本。
