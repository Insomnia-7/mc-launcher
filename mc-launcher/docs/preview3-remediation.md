# 方隅 1.0.0-preview.3：目录、任务与界面修复

基于 preview.2 工作副本推进，保留了此前智能体关于 Java 参数编码、危险操作确认等未提交修复。原有差异备份保存在本轮 D 盘交付目录的 preview2-existing-changes.patch。

## 对审查大纲的处理

| 审查项 | 实现 |
|---|---|
| F01–F03 路径选择与保存 | 未确认位置时阻止安装；新便携用户的数据在程序旁；既有用户保留原位置。失效游戏位置保留且不自动创建替代库。保存失败不切换内存状态。目录入口从网络页移至存储页。 |
| F02 迁移 | 当前游戏库支持校验复制后切换，原副本保留；快照、世界备份、封面偏好与同步方案的目录关联一起复制。启动器数据单独迁移，包含 Java、缓存、备份与配置，重启生效，游戏库位置保留。 |
| F04–F05 发现与外部库 | 常见位置及指定父文件夹的有限深度搜索；显示全部候选，不自动切换，不写入来源索引。外部库由玩家核对根目录或版本隔离运行目录后复制导入空文件夹，保留来源。 |
| F06–F08 存储与清理 | 链接、不完整读取等只影响相应项目，其他分类继续统计。显示总量、可回收量、路径及跳过项；扫描可取消。仅清理已知陈旧缓存，保留存档、备份、完整 Java 与断点文件。任务按实际目录关联判断清理冲突。 |
| F09–F10 任务 | 进行中与历史分开；支持单条移除和清空完成/已取消记录。保留未完成或清理失败任务。展示时间、实例与目录，并使用备份、恢复、修复各自的完成文案；已结束任务不显示无效控制行。 |
| F11–F12 页面状态 | 首次搜索占位、加载提示、保留翻页旧内容、结果淡入、追加及取消状态。搜索期间可切分类，迟到请求不能覆盖当前结果；失败翻页保留页码。游戏版本页不再显示旧 Modrinth 搜索状态。实例数量不再称为世界数量。 |
| F13 排版与控件 | 正文基准 15、辅助 13，扩大资源页过小文字；统一布局取整。按钮反馈使用位置与阴影，避免缩放文字。展开标题使用独立模板部件，避免继承默认选中底色。隐藏滚动条的偏好保留。 |
| F14 默认图案 | 用户否决几何样稿后，改为带像素纹理的溪流草甸透明图。首页与无自定义封面的卡片使用同一套素材；品牌图标和玩家封面保留。素材只解码一次并共享，无动画计时器。 |
| F15 交付 | 固定本次修改提交，单 EXE 的版本、源码提交及 SHA-256 记录在交付目录。 |

- 既有核心回归：867 项通过（离线夹具，包含本机回环网络模拟）。
- 新增目录/存储：26 项通过，含审查时原隔离链接夹具的扫描复验、来源不变、复制校验、取消清理、备份关联、非空目标保护。
- 完整桌面界面回归：297 项通过。
- 专项目录/任务/搜索界面：14 项通过，无绑定错误。
- 独立进程路径检查：4 项通过，覆盖首次不建库、保存选择、失效目录不回退、配置保存失败。
- 已检查浅色、深色、900×640 窗口，以及 100%/125%/150% 渲染输出；字体解析为 Microsoft YaHei UI。

渲染输出不等于切换 Windows 真实显示器 DPI。本轮不把 macOS/Linux 原生运行、真实微软登录或实际进入 Minecraft 世界写成已经验证。外部 PCL/HMCL 采用用户核对运行目录的复制导入，未宣称自动解析全部第三方隔离配置。

## 使用说明

打开“设置 → 存储”。“选择游戏位置”只切换路径；“迁移当前游戏库”复制并校验游戏及存档后切换；“迁移启动器数据”复制 Java、缓存和备份等，退出后重新打开生效。两种迁移均保留原副本，本轮没有替用户迁移或清理真实游戏文件。

当前交付供用户验收，尚未创建 GitHub Release。确认体验后再发布。
