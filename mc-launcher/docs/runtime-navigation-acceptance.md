# Java / Rust 客户端与导航拆分验收 · preview.19

状态：M0–M6 当前设备、实际发布包及远端发布验收通过。

## 功能边界

| 入口 | 职责 |
| --- | --- |
| 游戏实例 / Java | 保留现有 Java 版本、模组、整合包、启动参数和存档 |
| 游戏实例 / Rust 客户端 | Horizon 构建安装/导入、独立实例、资源准备、启动和日志 |
| 联机大厅 | 创建/加入房间、服务器及游戏连接 |
| 网络与连接 | 连接状态、全局游戏文件下载源、启动器代理 |
| 设置 | 外观、存储、设置同步和关于更新 |

网络与设置使用独立路由、独立视图和缓存。网络内没有外观标签；外观、存储、同步、更新命令均留在设置。还原代理编辑不会跳离网络页。下载源从 Java 实例设置移入网络，因为该值实际影响整个启动器。两种新路由的侧栏背景、选中状态和指示条一起更新。

## 保存与账号

构建元数据、Rust 实例、prepared 资源和独立游戏目录均在既有 D 盘数据目录下的 horizon 中。实例目录以独立ID建立，同名也不共用存档；准备资源按客户端与准备器哈希隔离。不直接改写已有 Java 存档。账号继续由原有安全存储管理，Rust 元数据不保存会话。每次准备与启动先刷新账号并核对当前档案和购买权益；会话通过 stdin 发送并关闭，启动日志脱敏。

官方 Nightly 在用户主动选择后下载到本地；方隅公开发布包不附带 Horizon EXE、游戏JAR、纹理、声音或转换资源。客户端日志在 Rust 实例的 fangyu-launch.log，另有上游 logs 与 crash-reports。下载/准备可取消，已有实例与存档保留。第三方许可说明单独交付。

## 实测限制

已验证当前 Windows 11、100% 缩放、隔离数据、真实工具接口及协议夹具。截图中的账号/游戏是测试数据。没有使用用户真实账号，也没有完成真实游戏资源转换、进入世界、真实服务器或长期兼容性测试。Windows10、其他真实DPI、IME组合与人工窗口手势仍待测。Java 模组与原存档兼容性不由 Rust 语言保证。许可分析保留在 horizon-integration-assessment.md，公益不等于自动获得 Minecraft 内容授权。
