# 启动图标与主界面就绪检查

1.0.0-preview.23 修复已有正版账号时，主界面先出现、头像随后补上，以及主页高亮在入场过程中被裁短的问题。

## 行为

- Windows 启动图标至少停留 650ms，同时准备当前账号头像、用户壁纸和导航布局；完成后才显示主窗口。头像的资料请求和图片下载、解码均计入准备过程。
- 资料服务的同步缓存读取在后台执行；等待网络时界面线程仍可响应。头像总等待预算为 8 秒，预算到期实际取消请求，以账号首字母代替不可用的头像，避免网络问题导致无法打开启动器。
- 关闭启动图标取消加载，不会稍后再次弹出主界面。关闭动画时仍执行准备，仅跳过视觉过渡。
- 导航高亮使用布局坐标，不把按钮临时的入场或按压变换当成布局变化。现有分区动画保持 800ms、错开 80ms；启动图标仍透明，主窗口仍为实色背景。
- Java 扫描和更新检测仍放在入场完成之后；启动已取得头像时不再重复请求。

## 验证范围

`Desktop.Checks --startup-native` 共 29 项：原有透明图标、文字无黑边、错峰入场及中断恢复，加上合成正版账号、延迟资料、延迟头像纹理、首帧头像、高亮完整宽度、取消、8 秒超时和无皮肤结果。延迟资料桩包含同步等待，以检查其不会卡住界面线程；纹理由本机测试服务返回，不访问真实账号。

账号测试先校验数据目录必须等于指定测试根目录下的 `data`，不匹配则停止。所有测试凭据均为固定假值，测试账号文件不打包、不上传。

发布检查使用实际发布的 Launcher 与密码库程序集；完整裁剪框架另用实际单文件 EXE 启动和退出验证。最终数量、文件版本和哈希见发布附件 verification.json。验收限本机 Windows 11 和合成账号延迟场景，未使用用户真实登录令牌。
