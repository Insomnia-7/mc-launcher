## 本轮交付：首次安装向导

空游戏目录自动显示向导；已有实例时保持原入口，左下角可手动打开向导。

1. 首帧后按需读取版本清单，仅列正式版，优先选择清单声明的最新正式版。
2. 自动推荐内存，检查 512–65536 MB 整数范围。
3. 使用当前微软账号或填写合法离线名；复用原设备码登录，并增加取消登录入口。
4. 一键调用现有 GameInstaller，含 assets，再按版本 javaVersion 准备 Java，旧版缺字段回退 Java 8。
5. 成功后保存所选内存、刷新并选中对应实例，默认继续调用原启动流程，也可取消勾选。
6. 取消和失败保留向导以便重试；设置在游戏及 Java 都成功后才写盘。已有 Java 路径、窗口和额外 JVM 参数不被覆盖。
7. 引导打开时不接受拖入文件，避免与向导安装并发；已有主任务运行时不打开向导。
8. 标题和操作区固定，表单在小窗口内可滚动；沿用原深色样式。

主要文件：

- `src/Launcher.Application/Install/FirstRunInstaller.cs`：可脱离 WPF 检查的安装编排。
- `src/Launcher.App/ViewModels/MainViewModel.Setup.cs`：版本加载、校验、取消、重试和启动衔接。
- `src/Launcher.App/Views/FirstRunView.xaml`：引导界面。
- `src/Launcher.App/ViewModels/MainViewModel.cs`：入口、首帧后加载、登录取消及状态通知。
- `tests/Core.Checks/FirstRunChecks.cs`：新增 15 项核心回归检查。
