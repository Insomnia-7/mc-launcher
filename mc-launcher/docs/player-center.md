# 方隅玩家中心 · 0.3.0-preview.2

Windows 用户直接打开 `方隅.exe`。现有游戏目录、账号库和主题设置继续沿用。

## 角色衣柜

从侧栏「角色衣柜」进入。拖动模型或按左右方向键旋转，可选择宽手臂 / 细手臂和外层显示。静置时不持续绘制，不引入浏览器或 3D 引擎依赖。

0.3.0-preview.2 调整了预览绘制：皮肤按像素清晰放大，关闭会混合相邻像素的平滑插值；相机略微俯视，侧面有明暗，隐藏背向镜头的面。光照缓存保留透明通道，皮肤外层不会被涂黑。PNG 的 DPI 元数据不再改变纹理坐标，预览区域略微增大。这些设置不修改原始皮肤、上传图片或游戏内分辨率。

- 正版账号：导入 PNG 后点击「上传到当前账号」，上传通过 Minecraft 外观接口执行。支持恢复默认皮肤、切换账号已拥有的披风、隐藏披风。导入本地衣柜不会自动上传。上传失败会保留错误原因，不显示成功。
- 离线身份：先为目标实例安装适配的 Fabric / Quilt / Forge / NeoForge，再点击「安装离线皮肤组件」。组件安装成功后导入皮肤、可选本地披风，点击「应用本地外观」。使用 CustomSkinLoader 的本地配置，不改变正版账号资料。其他玩家是否能看见取决于对方客户端及服务器配置。
- 皮肤为 64×64 或经典 64×32 PNG，披风为 64×32 PNG，单张最大 2 MiB。细手臂选择会保存到方案并传给组件。
- 各身份衣柜独立保存。切换为正版启动会移除本实例的方隅离线皮肤优先源；「停用游戏内本地外观」只移除方隅自己的配置与纹理，其他皮肤源保留。删除本地方案不会修改官方外观。

## 实例历史与预设

选好游戏实例，在游戏库点击「历史与预设」。对正在运行的实例，先退出游戏再修改配置或恢复数据。

- 手动快照保存实例内模组、配置、资源包、光影、游戏选项、启动设置及本地皮肤配置；勾选「同时备份存档」才会包含存档。共享资源、Java 和游戏版本二进制不重复打包。
- 恢复默认选「仅模组与配置（保留存档）」；恢复存档必须明确选择对应范围。恢复前另存当前状态，先校验备份，再提交替换；文件占用导致失败时回滚。误删的实例需先重新创建同名实例和相应游戏版本，快照不替代完整整合包导出。
- 安装资源、更新模组、应用预设及本地外观前自动保存实例快照。快照可在列表中删除，建议定期整理以控制磁盘占用。
- 设置预设保存内存、窗口及支持的画质、音量和按键。保留目标机器 Java 路径和额外启动参数，不复制账号。未知选项保留，新旧格式不兼容的按键跳过；模组配置仅允许相同游戏版本及加载器间应用。
- 更新频道明确区分「正式版 / 测试版 / 开发版」，检查兼容更新后，可选择安装、跳过这一版，或锁定当前模组文件。锁定项可单独解除；更新安装前自动快照。频道选择针对本次运行，文件锁定和跳过记录随实例持久保存。

## 任务与体检

从侧栏进入「任务与体检」。游戏安装、首次安装、资源下载、整合包导入及模组更新会保存为任务。

- 暂停保留任务参数、已下载文件和可续传断点。关闭启动器时等待当前任务暂停并保存；下次打开后手动选择恢复。
- 恢复沿用创建任务时固定的游戏 / 加载器 / 资源发布版本，先校验已有文件；支持 Range 的下载源继续传输，否则重新下载相应文件。完成的共享库和资源继续复用。
- 失败保留错误及重试入口。源压缩包移动或删除、下载源撤下版本等情况，需要先恢复对应来源。
- 取消清理本任务暂存目录和已登记的未完成文件，保留源压缩包、完整共享资源与原有实例数据。被占用无法清理的文件会提示路径。与暂停不同，取消后的任务不能继续恢复。
- 一次运行一个安装任务。忙碌时新任务保存为待开始，之后点击「开始 / 恢复 / 重试」。
- 中文体检检查 Java 要求、重复 Mod ID、可能的加载器不匹配和最近日志中的已知启动问题，显示依据与建议。规则体检不能保证所有模组运行逻辑都兼容。
- 诊断 ZIP 包含诊断摘要、模组列表和有限长度的日志尾部，过滤令牌、密码及 Windows 用户目录名，不包含账号库。日志格式可能包含其他私人信息，发送前仍可自行查看。

## 验收范围

核心流程使用隔离目录、模拟官方外观接口及真实 HTTP 下载实现检查；正版皮肤上传 / 披风切换未使用用户真实账号执行，离线外观未进入真实 Minecraft 客户端验收。Windows 独立 EXE 已实启验证；Linux / macOS 安装包和实机尚未验收。
