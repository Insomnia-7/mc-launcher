# 方隅：游戏工作区（0.4.0-preview.1）

本轮将原有功能整理为完整页面，继续使用现有 Avalonia / C# 框架与安装、账号、备份、任务实现，没有引入 WebView 或新的界面运行库。黑白界面配合原色游戏图标与插画。

## 导航与页面

| 入口 | 主要内容 |
| --- | --- |
| 游戏库 | 继续游玩、卡片 / 列表、搜索、收藏与分组、添加 / 导入 |
| 发现资源 | 保留资源检索、版本筛选、前置依赖、连续加载与每批数量 |
| 角色 | 账号外观、本地皮肤、披风、GPU 预览 |
| 下载任务 | 进度、暂停、恢复、取消并清理 |
| 设置 | 外观、动画、网络代理与游戏存储位置 |

点击游戏卡片或列表项进入该游戏的详情页：

- 概览：当前状态、显示名称、分组、封面、内存、Java 与账号入口。
- 模组与资源：已安装模组、更新频道、更新锁定、更新前备份和资源目录入口。
- 存档与备份：实例快照、可选存档备份、指定范围恢复、设置预设。
- 设置：该实例的内存、Java、JVM、游戏参数与窗口尺寸。
- 日志与诊断：实例体检、启动诊断、日志目录与脱敏诊断包。

启动按钮保持在详情页顶部。打开目录、导出和删除收进「•••」菜单；删除及恢复继续要求确认。角色、任务和全局设置不再占用遮挡主窗口的玩家中心弹窗。

快捷键 `Ctrl+1…5` 对应五个主入口，`Ctrl+,` 打开设置。`Esc` 优先关闭确认 / 账号 / 向导，再退出设置或回到游戏库。

## 游戏库数据

显示名称只影响界面，实例 ID、版本 ID 和磁盘目录不变。分组和收藏可组合筛选，名称、游戏版本和加载器均可搜索。启动成功交给进程适配器后记录最近游玩时间；重新打开启动器时选择最近游玩的游戏。

偏好文件保存在数据目录的 `library/<根目录摘要>.json`，封面保存在 `library/covers/`，不同游戏根目录相互隔离。切换根目录后重新加载对应偏好。卡片 / 列表布局随根目录保存，临时搜索词不保存。

封面最多 20 MB，导入时解码并保存 PNG 副本，显示时使用缩略图；删除源图片不会影响封面。无效图片会提示失败并保留原图。恢复默认封面后显示彩色版本图标和世界插画。

## 界面与运行

保留 14 px 基础正文、13 px 辅助文字与 28 px 页面标题。游戏卡片无硬描边，使用柔和阴影；导航和详情标签沿用选中底色与轻阴影。滚动条隐藏，保留滚轮和键盘翻页。

详情标签按需创建，页面切换继续使用已有可取消过渡。角色页离开后停止预览活动；退出角色入口时清理预览纹理。主窗口构造不请求公共网络接口。

## 验收范围

离线交互检查覆盖真实测试实例的启动准备、设置落盘、资源安装、前置依赖、连续加载、暂停与恢复、快照 / 预设、正版与离线衣柜操作，以及本轮新增的导航、收藏、搜索、分组、名称 / 封面保存和重启恢复。检查浅色、深色与 900×640 最小窗口布局。

交付继续采用 Windows x64 精简、自带运行环境、压缩单文件配置。最终裁剪后的业务程序集另做交互回归。Linux / macOS 尚未做本轮实机验收，不将 Windows 结果当作其他系统的验证。

后续轮次仍包括批量资源安装、更新变更预览、实例克隆以及更完整的存储与修复管理，本轮不将这些能力标记为已完成。
