# Preview 21 启动与资源界面验收

2026-11-16。用户已确认 B 风格及左侧项目依次舒展，明确要求仅启动图标背景透明，主界面保持实色；本批修复启动文字黑边并授权发布。

## 正式实现

- 启动标识使用独立的原生透明小窗口，没有窗口边框或单独的任务栏入口。图标素材不变，文字为纯白；只对该透明窗口文字设置灰度抗锯齿，无描边、阴影或模糊效果，避免 LCD 子像素渲染在透明背景产生黑色和彩色边缘。
- 图标阶段 280ms，随后 160ms 淡出。打开主窗口后，标题栏、左侧七个导航及底部区域、主页横幅和四个卡片依次舒展。单项 800ms，错开 80ms，使用与审看演示一致的三次缓出曲线。主窗口始终使用原实色背景。
- 尊重“关闭动画”和系统动画设置；本次仅在已验证的 Windows 环境启用透明启动标识。透明合成不可用时直接进入主界面。
- 主窗口在显示前准备初始状态，Loaded 后开启动画；完成后才开始后台检测。关闭动画、改变窗口尺寸、最小化、切页和关闭窗口均释放入场状态。关闭图标阶段也可取消启动。
- 保留此前确认的 B 页面切换：旧页尺寸冻结，300ms 淡出与轻微收缩，新页以最终布局 300ms 淡入与放大，避免闪屏和边距跳变。
- 合并此前本地通过的资源分类汉化、版本搜索、愚人节简介、分组条对齐、缓存页进度动画恢复和分类元数据刷新修复，详见 catalog-ui-regression.md。

## 检查

`Desktop.Checks --startup-native` 覆盖原生透明合成、无边框与任务栏、文字像素、主窗口实色、七项错峰、动画结束与中断恢复。文字截图统计 568 个可见像素，其中 322 个半透明边缘像素，黑边/彩边像素为 0。统计使用预乘 BGRA 的白色与 alpha 关系，不凭截图肉眼判定。

检查截图与 JSON 使用全新隔离数据，未包含用户账号、游戏数据或凭据。本机 Windows 11 检查，其他物理设备、系统缩放比例仍待对应环境实测。

该入口同时纳入本地 M6 和桌面发布工作流，资源目录检查保留在 M4/M6。GitHub 工作流修改须以后续远端实际运行结果为准。

构建源码、哈希、最终检查数量和实际发布包结果由 verification.json 与 release-history.json 记录。只有 update.json 与对应签名通过生产更新客户端后才公开新版。
