# preview.17：导航转场、指示条和安装标识验收

2026-11-16。状态：M0–M6 当前设备与实际发布包验收通过；远端发布验证进行中。

## M0：录像与复现

已读取用户提供的两段本地录像，分别约 5.67 秒、5.92 秒，1920×1080 / 60fps。确认旧页与新页淡入淡出时发生文字叠印，以及收起后切页再展开时指示条停留在旧横坐标。用户录像仅用于本地分析，不随 Release 上传。

## M1：转场方案确认与实现

先展示独立 420ms 整页上下滑动动画，用户明确选择采用并加快到约 300ms。本版使用 300ms 三次减速曲线，按主导航顺序向上/向下切换。两页始终不透明，在完整页高处相接，各自与宿主均裁切；不再交叉淡化文字。结束清空退场页，只有入场页接受输入。缓存视图保留，减少动画时立即切换。相同视图内的设置标签仍采用原有局部切换。

## M2：导航条修复

位置缓存从原点改为完整按钮矩形，展开宽度发生变化也重新计算指示条。X/Y 两个方向均有过渡，验证收起、换栏目、展开和快速反向操作，结束后贴合当前按钮右侧并纵向居中。

## M3：加载器识别图

Fabric 布料、Quilt 拼布、Forge 铁砧、NeoForge 狐狸及原版草方块使用重新绘制的矢量示意图。显示尺寸由微型图案改为 56 DIP，放入 72 DIP 底板。Forge 在深色主题使用更亮的金属色。五种选择与安装命令不变，署名及标识权利说明见 loader-illustrations.md。

## M4：行为与渲染

导航修复 38 项、原生页面转场 9 项、原生导航修复 5 项。覆盖相邻不透明页面中间帧、反向运动、退场清理、连续切页、缓存筛选/滚动、动画中断、卸载重挂载、减少动画、最小化和指示条横向滑动。
