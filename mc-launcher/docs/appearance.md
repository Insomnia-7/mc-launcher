# 外观、主题与壁纸

## 使用

点击左下角「外观与主题…」，或按 `Ctrl+,`。内置六套配色，点击即生效并保存：

| 主题 | 风格 |
| --- | --- |
| 深海玻璃 | 石墨灰蓝背景、柔和蓝色强调 |
| 冰川微光 | 浅色背景、清晰深色文字 |
| 紫晶暮色 | 低饱和灰紫背景、淡紫色强调 |
| 松林薄雾 | 低饱和灰绿背景、薄荷色强调 |
| 日落琥珀 | 暖灰背景、琥珀色强调 |
| 极光青屿 | 深灰青背景、青绿色强调 |

界面采用半透明面板、细边框、圆角与随主题变化的背景光晕。导入壁纸后，对背景图片做轻度模糊和遮罩，前景文字保持清晰。这是 WPF 内实现的玻璃质感，不依赖系统原生液态玻璃合成器。

左侧改为浮动圆角侧栏，保留「游戏库 / 发现」入口和资源分类；主操作集中在内容区，账号管理仍位于版本页。采用 Microsoft YaHei UI 优先的字体栈，正文使用中性色，强调色集中于主操作与选中态；统一字号、按钮高度、输入框和间距，下载筛选采用同一组控件，支持手动输入游戏版本。最小窗口为 820×560，外观面板内容可滚动。

## 导入壁纸

1. 点击「选择图片」，选择 PNG、JPG、JPEG 或 BMP，文件最大 24 MB。
2. 拖动「显示强度」预览，范围为 0–85%，默认 55%。设置自动保存。
3. 点击「恢复默认」移除启动器保存的副本，恢复主题背景。

导入时复制图片到启动器数据目录的 `appearance-data`，不移动或删除用户选中的源文件。替换成功后仅清理启动器先前保存的图片副本；导入或保存失败时保留原壁纸。解码在后台进行，显示宽度限制为 1600 像素，启动恢复安排在首帧之后。

外观保存在数据目录 `appearance.json`，与原有账号、代理和游戏设置分开。默认数据目录为 `%APPDATA%/MCLauncher`，可沿用 `MCLAUNCHER_HOME`。本机外观设置和图片副本已加入 Git 忽略规则。

## 导入和分享主题

「导出配色」生成 JSON 颜色文件；「导入主题」载入并应用。内置主题始终保留，另外保留一个自定义主题槽，下一次导入替换该槽。

可从 [日落玻璃示例](themes/sunset.json) 开始修改。文件采用 `schema: 1`，名称最多 40 个字符，最大 32 KB。`colors` 接受 `#RRGGBB` 或 `#AARRGGBB`，遗漏项继承深海玻璃。可配置项为：

```text
BgBrush PanelBrush CardBrush FieldBrush HoverBrush LineBrush
TextBrush MutedBrush FaintBrush AccentBrush AccentHoverBrush
AccentFillBrush AccentPressedBrush SelectedBrush SuccessBrush
WarnBrush DangerBrush DangerSoftBrush OverlayBrush WallpaperTintBrush
```

自定义主题作用于颜色，不导入布局、字体、XAML 或脚本。导出的主题不包含壁纸、源图片路径、账号或个人设置；分享壁纸需另行提供图片。当前仅支持以上 JSON 主题格式，不能直接导入其他启动器的主题包。

## 动画与快捷键

页面在完成布局后播放 280 ms 淡入和 340 ms 位移，退出采用 180 ms 淡出，淡出完成后才隐藏。资源分类切换前保留旧画面的临时快照，旧内容在 210 ms 内退出，新内容同步进入；结束后立即释放快照。弹窗的遮罩淡入，内容卡片另做轻微缩放与位移，避免整块遮罩滑动。快速反复切换以最后一次选择为准。

外观面板提供「流畅动画 / 跟随系统 / 关闭动画」。默认流畅模式，无须开启 Windows 动画开关；选择跟随系统才读取系统偏好，关闭时直接切换。旧配置缺少该字段时使用流畅模式。

- `Ctrl+1`：游戏版本。
- `Ctrl+2`：下载。
- `Ctrl+,`：外观与主题。
- `Esc`：关闭最上层可关闭的面板。

按钮提供悬停、按下、键盘焦点及禁用反馈，不引入额外的动画库。
