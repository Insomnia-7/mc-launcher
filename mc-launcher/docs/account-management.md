# 多账号管理

## 功能与交互

版本页「账号管理…」打开已保存的游戏身份列表，支持选择正版账号或离线身份、添加微软账号、编辑离线用户名和移除所选正版账号。首次安装向导通过同一入口选择身份。

账号切换先保存再更新界面，启动器重新打开时恢复上次选择。仅选择列表项不会立即改变正在使用的身份，需点击「使用此身份」。添加账号使用既有设备码登录流程，取消或失败保留原有账号；同 UUID 再次登录更新原条目，不重复新增。

移除账号使用既有确认层，只清理本机的登录记录。移除非当前账号时保留正在使用的身份；移除当前账号时回到已配置的离线身份，不自动选择另一个正版账号。旧版单账号文件一并清理，避免移除的登录信息遗留或被后续迁移恢复。旧文件无法清理时明确提示。

账号登录、游戏启动与安装向导运行期间阻止冲突的身份操作。正在运行的游戏继续使用其启动时的身份，列表切换只影响后续启动。列表优先显示当前账号；最小窗口内可以滚动和操作。

## 保存与隐私

复用现有 AccountLibrary 和 DPAPI，文件格式不变。新增 Copy 获取独立快照，所有账号编辑先在副本完成并保存；保存失败时内存中的身份与原账号簿保持一致。初始化不再为设置离线名而重写账号文件。

界面使用仅含 UUID、显示名称、状态和当前选中标记的 AccountChoice，不绑定带令牌的账户对象。列表不展示令牌，日志不新增凭据输出；旧版和临时账号文件被排除在 Git 提交范围之外。测试全部使用虚构账号和隔离目录。

## 启动时验证

只验证当前选中的正版账号，打开账号列表或构造窗口时不调用网络认证。
取消验证继续传播取消信号。验证失败保留当前正版选择并停止启动，提示重新登录或主动切换离线身份，修正原先失败后悄悄使用另一离线身份的行为。续期返回的 UUID 必须与所选账号一致，新刷新令牌成功保存后才用于这次启动。

## 验证范围

- Release 解决方案构建：零错误、零警告。
- 507 项核心检查通过；新增账号副本的选择、删除和离线名称隔离检查。
- 75 项 WPF 流程检查通过，包含 33 项新增检查：账号初始化、无网络切换、重载恢复、离线身份、保存失败及重试、取消登录、重复登录、确认移除、旧记录清理、续期成功与失败及取消、异常身份拒绝和任务互斥。
- 1000×640、820×560 布局渲染并目视核对，长列表可滚动。
- 架构检查通过，核心层未增加 WPF / Windows 依赖，没有新增运行时依赖。

WPF 验证使用替身认证与测试保护器，覆盖登录结果写入和续期编排，不打开真实浏览器、不改变真实剪贴板、不读取个人账号数据。本轮未重新完成真实微软设备码授权、联网账号续期或进入游戏的验收。
