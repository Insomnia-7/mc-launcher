# 参考图 UI 重构验收（preview.16）

本次以用户在 2026-11-15 提供的深浅双主题参考图为版式依据，替代 preview.15 的简化工作台主页。原启动器图标保留。参考板上的标注、标题、对照窗口和交互说明不进入产品。

## M0：冻结页面映射

- 主页顶部固定、横跨内容区的 MC 光影风景横条，约 7.6:1；不依赖实例数量或用户壁纸配置。
- 横条文案：专注于更好的 MC 联机体验；更稳定、更便捷、更流畅。
- 侧栏依次为主页、游戏实例、联机大厅、网络与连接、资源管理、下载中心、设置。
- 横条下方两列两行：快速启动 / 联机与网络状态；游戏实例管理 / 快捷功能。左右列比例 1.65:1。
- 六个快捷功能严格为三列两行，顺序与参考图一致。

## M1：外壳与控件

深色使用炭灰蓝底、紫灰卡片和紫色高亮；浅色使用淡薰衣草底和近白卡片。两主题的主按钮均为饱和紫底白字。保留键盘焦点、原生命中区、窗口缩放及减少动画选项。侧栏选中条沿右侧移动，按钮保留悬停、按压和释放反馈。

## M2：首页与真实操作

顶部横条、四块卡片、三条实例预览、实例选择器、启动按钮、行内启动与菜单均验收。预览列表只取真实库前三条，完整库通过“全部实例”进入。筛选实例页不影响首页选择器。空库保留横条与四卡框架，提供安装和导入入口。

## M3：六个快捷功能

新建实例、导入整合包、管理模组、管理资源包、打开游戏目录、日志与调试连接既有业务命令。资源包和目录操作在空库禁用；模组和诊断入口进入当前实例对应页。

## M4：网络与导航

联机状态和延迟显示实际业务状态，未测速显示未测速。当前没有 NAT 探测结果，因此明确显示未检测，不复制参考图中的在线、28ms、开放等演示数值。网络导航指向现有网络设置。

## M5：一致性与回归

对深浅主题、实例管理、安装与资源、联机、账号与设置开展现有业务回归。检查主按钮白字、字体与背景对比、卡片边界及紧凑窗口可达性。

## M6：实际画面与发布

检查真正运行的首页截图，确认横条始终存在、四卡位置、六按钮顺序及真实风景图加载。测试本机原生标题栏、侧栏中间帧、最大化和还原；渲染倍数测试不能替代真实操作系统 DPI。构建单文件后校验裁剪程序集、实际单文件启动、签名更新清单、源提交、资产哈希，再按既有约定发布预览版。

状态：M0–M5 及 M6 当前设备渲染、原生窗口验收通过；发布包与远端验证进行中。

本轮检查：Core 880、首页 53、外壳 14、实例管理 71、安装资源 103、联机 31、账号设置 49、一致性 36、原生窗口 20，共 1,257 项，另通过架构护栏。当前 Windows 11、系统缩放 100%。测试场景使用独立数据和确定性业务夹具，不代表真实远端联机或真实游戏客户端实测。

待测：Windows 10；125/150/200% 真实系统缩放；人工拖动、八方向拉伸和 Snap 悬停；真实远端联机和模组客户端。

生成风景为原创 MC 光影场景，不是参考图中原始风景文件的逐像素副本；产品版式、文案与控件排列按参考图实现。
