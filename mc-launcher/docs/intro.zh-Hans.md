# 方隅简介

方隅是一款 Minecraft Java 版启动器，面向 Windows 桌面，用 C# 和 .NET 10 编写，界面基于 Avalonia。它以单文件形式分发，下载后双击即可运行，不需要预先安装 .NET 运行时。

它的定位是做一款「够用且不出岔子」的启动器。Minecraft 启动环节里最容易出问题的部分——版本 JSON 的继承合并、classpath 拼接、Java 版本匹配、natives 解压、中文路径下的参数传递——都收敛在可单独测试的领域层里，界面上只负责把事情展示清楚。启动失败时给出的是能看懂的结论和下一步，而不是一整屏堆栈。

除了启动游戏本身，方隅提供日常会用到的配套能力：原版与 Forge、NeoForge、Fabric、Quilt 的安装，实例与版本的分组管理，Modrinth 与 CurseForge 的资源检索，模组批量管理与更新预览，世界存档的单独备份与恢复，以及按需共享的游戏设置同步。联机部分支持扫描局域网世界，也可以通过 EasyTier 组建跨网络的私密房间，相关组件按需下载，不安装虚拟网卡，也不修改系统路由。

项目采用 MIT 协议开源，由个人维护，处于预览阶段。Windows 版本持续迭代；Linux 与 macOS 的原生包已能构建和启动，但真实游戏运行与微软授权流程仍需要在这些平台上完成验收。项目与 Mojang、Microsoft 没有关联，也不是官方产品。
