# 实例依赖和删除选项验收

## 本批行为

加载器通过 `inheritsFrom` 或 `x-launcher-parent` 使用基础版本。基础版本属于安装依赖，不作为可玩原版实例显示；这个角色写入 `instances/dependency-versions.json`，即使加载器被移除也不会改变。明确选择原版安装会写入独立实例元数据并清除该依赖角色。

兼容旧版已经创建的无元数据基础版本目录；真正带实例元数据的纯原版和整合包保留。删除实例时先检查共享引用，最后一个使用者删除后清理未共享的父版本和解压库。共享 libraries、assets 不在本批删除范围。

删除确认增加默认不勾选的 Java 清理选项。仅匹配启动器 `java/<主版本>/bin/java.exe` 中自动管理的运行时；根据指定路径或版本要求确定目标，检查已记录游戏库中的实例以及运行中的 Java。共享、运行中、无法核对的离线游戏库所关联的 Java 保留。不会扫描所有磁盘，也不处理其他软件安装的 Java。

下载气泡展开时在导航项右侧，收起时在图标右上角；数字按实际宽度水平和垂直居中。整合包下载任务不再绑定当前选中的其他实例。

## 验证范围

使用 D 盘隔离的合成游戏库和账号，不修改用户真实游戏目录。回归包含两种父版本格式、带 settings 的旧基础目录、删除后重建索引、明确安装原版、多层继承、多个整合包共享、实际整合包导入和删除、跨游戏库 Java 共享、运行时占用、外部 Java 路径拒绝，以及删除选项绑定和气泡布局。

Windows 为本批验收目标；其他物理系统和用户实际账号游戏会话不作为本批已通过项目。保留现有动画、跨平台核心和未来平台入口。
