# 资源检索、活动版本与磁盘清理交接（2026-10-23）

## 本轮范围

项目代码位于仓库的 `mc-launcher/` 目录，保留 .NET 10 / WPF 和 Domain / Application / Infrastructure / App 分层。

### 统一资源检索

模组、整合包、资源包、数据包、光影包共用检索页。提供关键词、来源、可输入的 Minecraft 版本、平台分类、适用类型的加载器、重置、热门推荐、首页 / 上页 / 下页 / 末页。保留已有本地整合包导入入口。

通过平台端进行分页与排序，而非仅重排当前页。Modrinth 的相关度 / 下载量 / 热度 / 最近更新 / 最新发布分别对应 relevance / downloads / follows / updated / newest。CurseForge 对应其官方人气、总下载量、更新时间、发布时间排序；其 API 未提供单独的相关度选项，因此相关度采用默认人气排序，控件提示说明该区别。CurseForge 搜索前 10,000 项的限制在分页中明确体现。

分类通过各自的官方 taxonomy 接口获取；Modrinth 数据包采用 all_project_types:datapack 与 categories:datapack，安装时再用 datapack 文件过滤，避免把跨类型项目的模组 JAR 当成数据包。CurseForge 按 classId 检索，并拒绝类型不符的 ID 直读结果。

默认进入资源页展示空关键词的热门结果。搜索版本不受当前实例暗中约束；整合包安装遵循用户明确选择的游戏版本 / 加载器，其他资源安装继续以目标实例兼容性为准，显式筛选与目标实例的版本 / 加载器不一致时拒绝安装并提示切换。数据包仍下载到实例 `.minecraft/datapacks`，用户需移入目标世界，这一点在 README 中说明。

构造下载页不发资源请求，首次访问才加载。筛选元数据独立获取、最多等待 10 秒，不阻塞搜索结果呈现；分类缓存复用。每页 20 项，列表开启虚拟化。切换类型 / 来源时取消旧查询并丢弃过期响应；改条件清除旧分页；失败与取消恢复可操作状态。

CurseForge 使用用户现有的 Key 配置，未收录任何密钥。未配置或搜索被拒时明确提示；403 保留数字项目 ID 直读。无搜索权限时无法提供该来源的热门列表，不伪造结果。

### 活动版本

版本类型独立为正式版、预览版、活动版、远古 Beta、远古 Alpha；未知类型仍进入其他。活动版本按明确官方版本 ID 识别，避免把普通 4 月快照误归活动版。安装仍走官方元数据及已有下载器，不增加来历不明的文件链接。

真实官方清单中确认 9 个可读取元数据的活动版本：26w14a、25w14craftmine、24w14potato、23w13a_or_b、22w13oneblockatatime、20w14infinite、3D Shareware v1.34、1.RV-Pre1、15w14a。已知但不在清单中的 ID 不额外伪造下载项。仅收录有可靠官方元数据的特殊版本。

### 删除与历史目录

原删除流程先删实例目录再重新加载登记表；扫描仍在磁盘上的版本时会重建一个同 ID 的虚拟实例，使版本目录被误判为仍在使用。改为删除前快照，排除自身，检查其他真实实例与版本继承依赖后回收版本目录和该版本 natives。共享 libraries / assets、仍被实例或加载器依赖的版本继续保留；索引同步移除。非法 ID 和指向外部的目标目录链接会被拒绝。

隔离测试产生的临时游戏根目录已清理。主游戏数据和存档保留；共享缓存、安装包缓存和诊断日志不随单个版本自动删除。
