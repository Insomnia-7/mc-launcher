## 真实游戏验证

`--real-game` 是显式启用的联网验收入口，使用正式 Mojang 元数据、下载器、Java 检测、持久任务和 `WinProcessLauncher`，不使用测试 Java 或假游戏进程。
本批在 D 盘隔离目录下载 Minecraft 1.20.1，使用本机 Java 17、2048 MiB 内存和独立离线测试身份。
已验证真实安装任务开始、取消后恢复交互、重试安装、实例列表选择、主界面启动命令、`Minecraft 1.20.1` 窗口、OpenAL 与纹理图集初始化、启动器恢复交互，以及发送关闭窗口消息后的退出码 0。

未登录或修改用户微软账号，未进入存档、加载模组或连接真实远程房间；这些项目不标记为通过。只停止本次验收创建的游戏进程，不操作用户已运行的启动器或游戏。

## 复验入口

在源码根目录使用 PowerShell 7：

```powershell
./scripts/check-ui-m9.ps1 -Dotnet D:\dotnet\dotnet.exe -Native
# 显式联网、下载数百 MB 游戏并创建真实游戏窗口：
./scripts/check-ui-m9.ps1 -Dotnet D:\dotnet\dotnet.exe -Native -RealGame
```

默认输出位于工程 `mc-launcher/scratch/ui-m9`；日志、游戏库和截图保留本地，不加入源码或 Release。
使用独立构建目录复验时保留用户正在运行的程序；发布标签与最终 EXE 的 ProductVersion 后缀由签名发布流程核对。
本版本仍为 Pre-release，其他系统和设备补测完成前不宣称整个 M9 人工矩阵已关闭。
