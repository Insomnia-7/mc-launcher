# 一起游玩：局域网与跨网络私密房间

1.0.0-preview.5 在 Avalonia 桌面端加入「联机」页面。局域网发现和手动服务器连接无需安装额外组件；跨网络房间使用可选的 EasyTier 2.6.4。公开联机大厅不在本版范围。

## 局域网

1. 房主进入 Minecraft 单人世界，按 Esc，选择「对局域网开放」。
2. 朋友在方隅「联机 → 局域网」中扫描世界，点击「使用地址」。扫描一次持续约 3 秒，不会一直后台搜索。
3. 选择相同游戏版本的实例，检测连接后「启动并连接」。游戏已经运行时，复制地址到 Minecraft「多人游戏 → 直接连接」。

扫描使用 Minecraft 的 UDP 4445 / 224.0.2.60 广播。访客网络隔离、系统防火墙或不同子网可能阻止发现，此时可手动填写房主的局域网地址和游戏实际端口。状态检测支持 Minecraft Java 1.7 及之后的状态协议，不会代替游戏登录。

## 跨网络私密房间

1. 双方在「跨网络房间」点击「下载 / 修复组件」。Windows x64 首次从 EasyTier 官方 GitHub 下载约 31.1 MiB 的 ZIP；只提取 core 程序，保留原 ZIP 供启动前校验，总占用约 54.4 MiB。组件位于启动器数据目录的 `multiplayer/engines` 下。
2. 房主先进入单人世界并开放局域网。可以扫描后点击「共享本机世界」填入端口，也可以手动填写游戏显示的随机端口。专用服务端同样可填写本机服务端口。
3. 房主填写一个双方可达的公共或自有 EasyTier 节点，例如 `tcp://节点主机:端口`。页面提供 EasyTier 官方社区入口；公共节点由第三方运营，性能及可用性由运营方和网络决定。本版不内置一个未经验证的固定免费节点。测试时上游安装脚本中的旧 `public.easytier.top` 域名无法解析，因此没有将它作为默认值。
4. 点击「创建房间」，将完整的 `fangyu-room://` 邀请信息发给朋友。邀请包含私密房间密钥，有效期 12 小时，仅分享给信任的人；邀请不保存到历史记录或日志。
5. 朋友粘贴邀请并连接，等待「游戏可连接」。本机地址形如 `127.0.0.1:随机端口`，只在加入者自己的电脑使用。选好游戏实例后启动连接，或把这个地址粘贴到已运行的 Minecraft 中。
6. 联机期间双方保持方隅运行。房主关闭世界、点击断开或退出方隅会中断连接；退出活动房间前会确认。断开会结束本次组件进程并删除临时邀请配置。

双方应使用一致的游戏版本、加载器和模组组合。启动器根据房主选择的实例附带版本提示，但不能验证房主实际运行的模组文件完全一致。邀请码不是短数字口令；已有邀请不能通过系统 URL 自动启动程序，必须在页面中手动粘贴。公开服务器的账号验证仍由 Minecraft 和服务器完成。

## 实现与性能

- 首屏不扫描网络、不下载或启动 EasyTier。房间停止后不保留常驻联机进程；仅在活动房间中每 5 秒检测游戏状态。
- 房间使用无 TUN 模式，未安装虚拟网卡、驱动、系统服务，也不修改系统 DNS、默认路由或防火墙规则。
- EasyTier 负责协商连接及穿透/中继。只有实际 Minecraft 状态请求成功才显示「游戏可连接」，进程启动成功不代表穿透已经完成；本版不展示未验证的直连率或路径类型。
- 游戏 TCP 入口只绑定回环地址，房主仅允许本次游戏端口；不作为通用出口节点，不为其他房间提供中继。
- 下载固定上游版本、大小和 SHA-256，启动房间前再次核对 ZIP 和 core；可取消下载，取消不会破坏原先已安装组件。会话配置不进入命令行或持久日志。
- 启动连接使用一次性参数：现代版本使用其 Quick Play 参数，较旧版本使用 server/port。不会改写实例的额外启动参数或服务器列表，后续普通启动不携带此地址。

## 验证范围

已验证真实 UDP 收包、去重、本机识别和取消；真实 Minecraft TCP 状态握手；实际 EasyTier 官方 Windows core 的无 TUN 三节点转发、错误密钥拒绝、取消启动及退出清理。三节点试验使用隔离的本机中继和模拟 Minecraft 状态服务，经过真实 TCP 和官方 core，不等于两台异地电脑的实机游玩验收。

公共节点试验未通过：旧默认域名在测试环境无法解析，另一个社区节点 TCP 连接超时。跨网络功能可配置节点，但仍需使用可达节点进行双机异地及不同 NAT 网络的游玩试验。Linux/macOS 的组件目录覆盖 x64/ARM64，本次未重新发布或进行其原生联机实测。

本次未加入好友账号体系、公开大厅、常驻房间服务或语音。Windows 单文件仍自带运行环境，联机组件按需下载，不塞入启动器 EXE。

## 上游与许可

可选组件来自 [EasyTier 官方 v2.6.4](https://github.com/EasyTier/EasyTier/releases/tag/v2.6.4)，以独立进程运行，未修改上游二进制。源码及许可见 [该版本源码](https://github.com/EasyTier/EasyTier/tree/v2.6.4) 和 [LGPL-3.0 许可证](https://github.com/EasyTier/EasyTier/blob/v2.6.4/LICENSE)。固定资产地址和哈希见 `src/Launcher.Infrastructure/Multiplayer/EasyTierPackages.json`。

可重复验证：`Core.Checks --multiplayer`、`Core.Checks --multiplayer-engine`、`Desktop.Checks <隔离目录> --multiplayer`。原生引擎检查须设置 `FANGYU_EASYTIER_ARCHIVE` 为固定官方 ZIP 路径；可选的 `--multiplayer-public` 通过 `FANGYU_EASYTIER_PEER` 指定公共或自有节点。所有测试目录和临时数据使用 D 盘。
