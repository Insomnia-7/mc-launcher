3. 视觉风格配比
3.1 主风格：Linear × Arc
这是整个产品的主体设计语言。

3.2 辅助风格：Fluent 2 × Discord
只借鉴其交互与信息组织优势：

- 选中状态清楚。

- 弹窗与背景的空间关系。

5.3 空间分配原则
- 横幅高度适中，不做成大型广告主视觉。

- 联机与网络状态不能挤压快速启动。

- 快捷功能区域不应占据过大面积。

- 1366 × 768 下也要保证核心操作可见。

- 切换导航时平滑移动。
- 背景高亮同步过渡。
- 图标和文字颜色同步更新。

15. 动效设计规范
动效强度为丰富，但不能让整个界面持续运动。
页面切换
旧页面： - Opacity 1 → 0。 - Y 轴 0 → -4px。
新页面： - Opacity 0 → 1。 - Y 轴 8px → 0。
建议总时长 180--240ms。
内容交错入场
建议顺序： 1. 页面标题。 2. 首页横幅。 3. 快速启动。 4. 联机状态。 5.
游戏实例。 6. 快捷功能。 7. 辅助信息。
每个组件入场约 180--260ms，相邻延迟约 35--55ms。
侧边栏展开收起
- 宽度在 240px 与 72px 之间过渡。
- 图标平滑调整位置。
- 文字淡入淡出。
- 文字轻微水平位移。
- 展开时先准备布局再显示文字。
- 收起时先隐藏文字再压缩空间。
建议总时长 220--280ms。
按钮反馈
Hover： - 背景、边框、图标颜色平滑变化。
Pressed： - 轻微缩放，Scale 建议 0.97--0.99。 - 松开后自然恢复。
建议： - Hover：100--140ms。 - Pressed：70--100ms。 -
Release：120--160ms。
弹窗
打开： - 遮罩淡入。 - 弹窗 Opacity 0 → 1。 - Scale 0.97 → 1。 - Y
轴轻微位移。
关闭使用反向动画。
Tooltip
- 延迟约 400--500ms 显示。
- 轻微淡入和位移。
- 收起时快速淡出。
Toast
- 从窗口右下方或统一通知区域进入。
- 支持成功、失败、警告和普通信息。
- 支持手动关闭和自动消失。
- 多条通知有序排列。
动画原则
- 不使用无意义的无限循环动画。
- 不使用夸张弹跳。
- 不允许动画阻塞业务操作。
- 支持减少动画模式。
- 动画必须能够处理快速连续点击和中断。

21. 主题管理实现
实现三种主题模式：
public enum ThemeMode
{
    System,
    Light,
    Dark
}
需要实现：
- 当前主题读取。
- 主题切换。
- 系统主题跟随。
- 主题设置持久化。
- 运行时动态资源更新。
- 全局组件同步切换。
- 重启后恢复用户选择。
主题切换不能重建整个窗口，也不能丢失当前页面状态。

27. 动画系统实现
建立统一的 Motion Tokens。
建议参数：
  动画                   时间
  Hover            100--140ms
  Pressed           70--100ms
  Release          120--160ms
  导航提示条       160--220ms
  侧边栏           220--280ms
  文字淡入淡出     120--160ms
  页面切换         180--240ms
  内容入场         180--260ms
  弹窗             180--260ms
  Tooltip          120--160ms
实现分工：
- 简单属性变化优先使用 Avalonia Transitions。
- 多阶段动画使用 Avalonia Animation / Keyframe。
- 确实有性能需求时使用 Composition Animation。
- 不要将所有动画放进 C# 定时器。
- 不要在每个 View 中重复定义一套时间参数。
必须处理动画中断、快速重复操作和控件卸载。

- 弹窗层级清晰。

- 深浅色模式分别适配。
不要为了模拟 Mica 而创建复杂且持续刷新背景的视觉树。

31. 性能和稳定性要求
禁止：

- 频繁创建和销毁整个页面。
- 每次切换主题重建主窗口。
- 大量高成本模糊。
- 过多实时阴影。
- 事件订阅不释放。
- UI 线程执行耗时业务操作。
- 动画阻塞启动命令。
- UI 改造破坏现有数据存储。
所有业务操作继续通过现有 Service、Command 和 ViewModel 执行。
