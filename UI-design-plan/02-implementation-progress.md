## 本批实现

- 沿用 `MainWindow` 的原生装饰角色，不为拆分组件更改既有控件名称。
- 标题栏使用原始品牌图标；页面标题覆盖游戏实例、资源、角色、下载任务、联机、设置和实例详情。
- 主题按钮调用已有 `CycleThemeModeCommand`，模式、图标与无障碍说明同步更新，不重建窗口。
- 标题栏后台任务入口绑定真实持久任务状态，空闲时隐藏，点击进入原任务中心。
- Windows 按 Mica → AcrylicBlur → None 请求材质，仅在实际生效后使用透明窗口及高不透明度外壳底色；主要业务内容保持实色。
- 自定义壁纸优先，加载后停用系统材质，移除壁纸后恢复材质请求；非 Windows 继续使用原生边框和实色底色。
- 非最大化窗口显示不拦截点击的细边框；最大化沿用 `OffScreenMargin`，快速切换窗口状态后图标与真实状态保持一致。

## 验证范围

执行 `MinecraftLauncher.Desktop.slnx` Release 构建、架构检查、Core.Checks、Desktop.Checks 主套件，以及以下专项入口：

```powershell
dotnet mc-launcher/tests/Desktop.Checks/bin/Release/net10.0/Desktop.Checks.dll <新的空目录> --shell
dotnet mc-launcher/tests/Desktop.Checks/bin/Release/net10.0/Desktop.Checks.dll <另一个空目录> --shell-native
```

`--shell` 验证页面标题、主题循环与持久化、页面状态保留、材质回退、壁纸互斥、760/820/1180px 布局及快速最大化还原后的图标。

`--shell-native` 在真实 Windows 窗口上验证拖动区 HTCAPTION、主题按钮 HTCLIENT、最大化按钮 HTMAXBUTTON（Snap Layouts 命中角色）、窗口外框 HTLEFT、双击最大化、还原、最小化与最大化边界，并记录实际材质和当前屏幕缩放。

本机实际生效材质为 Mica，屏幕缩放为 100%。100% / 125% / 150% / 200% 图片输出已经生成；这些是渲染倍率检查，不等于四种系统 DPI 实机测试。Windows 10 实机材质回退、其他系统 DPI 的窗口行为与 Snap 浮层的人工操作留待 M9 验收。Linux/macOS 本批不重新发布。

## preview.9：M4 侧边栏交互

- 收起：文字在 120ms 内渐隐并左移 6px，再切换紧凑布局；宽度在 250ms 内从 240px 变为 72px。
- 展开：先扩宽，80ms 后开始 140ms 文字渐入；连续反向复用正在运行的过渡，从当前可见宽度衔接。
- 品牌区预留固定高度，展开与收起时导航不会纵向跳动，保留原始 Logo 与 42×32 折叠键。
- 整个导航只有一个选中胶囊和一条 3×20 指示条，两者用 190ms 位移跟随真实页面；首次布局和减少动画时直接落位。
- 收起态导航启用 450ms 中文 Tooltip，展开态抑制重复提示。
- 收起态保留 32×32 账号入口（已有皮肤头像优先，无头像时显示身份图标），新版本提示也保留紧凑入口。
- 任务角标根据真实未完成任务计数，包括运行、等待、暂停和失败；完成和取消后移出计数，不受任务中心历史筛选影响。
- 导航文案对齐游戏实例、下载中心、联机大厅、角色衣柜、任务中心与设置。主页尚无真实页面，随 M6 接入，不新增空入口。
- `--sidebar` 覆盖中间帧、快速反向、偏好写盘、布局、账号入口、浮层及减少动画；`--sidebar-native` 在真实 Windows 窗口验证动画确实发生。完整桌面回归另外覆盖真实任务角标变化。

验证仍限当前 Windows 100% 系统缩放；其他系统 DPI 与跨平台实机留待 M9。下一阶段为 M5。


## preview.10：M5 页面过渡与交错入场

- `MotionTokens` 为交互角色提供统一时长。侧栏、文字、Tooltip 延迟、页面和入场共用该来源，旧组件保留转发别名；基础按钮使用 Hover / Pressed / Release，完整八态仍属 M7。
- `AnimatedContentHost` 使用实色 BgBrush 根容器和两个轻量 ContentPresenter。旧页在 110ms 内淡出并上移 4px，新页在 200ms 内从下方 8px 淡入；根容器不透明度始终为 1，退场层不接收点击。
- 导航通知合并至最终页面，避免中间业务状态反复切页。每次切换递增版本、取消前次等待；仅当前版本可清空旧层和归位，结束后只挂载当前页。
- 各业务视图继续缓存，往返保留筛选和滚动，不额外发起网络请求。卸载、关闭、快速往返和中途关闭动画都会清理退场层；减少动画使用瞬时切页。
- 首次游戏库按现有可见模块使用 220ms / 40ms 交错入场，之后切回不重播；全程不禁用交互。七段序列已专项验证，完整首页的七个业务模块尚未存在，由 M6 布局接入，未新增占位卡片。
- `--page-motion` 覆盖状态保留、30 次快速切换、卸载重挂载、七段顺序与取消、减少动画即时归位；`--page-motion-native` 验证真实中间透明度 / 位移、实色背景、连切与最小化还原。侧栏无头采样隔离整页软件绘制，原生侧栏检查仍同时渲染页面和指示条。

本批仅发布 Windows x64。当前原生验证仍为 Windows 100% 系统缩放，其他 DPI 与跨平台实机留待 M9。下一阶段为 M6。


## preview.11：M6 默认首页与真实业务卡片

- 新增 `HomeView` 与“主页”导航，默认启动进入主页；原“游戏实例”管理页及其筛选、列表/卡片布局保留。主页、详情、设置、联机、角色与任务之间共用原有导航和 M5 页面缓存。
- 首页内容区顶部间距 8px，横幅固定 88px，复用内置世界插画与固定文案；首行固定 144px，左右按 1.65:1 分配。实例管理区域填满剩余高度，底栏显示实际游戏目录摘要、Java 选择方式和最近游玩记录。高度不足时允许纵向滚动。
- 快速启动下拉同步 `SelectedInstance`，主操作和取消复用 `LaunchCommand` / `CancelCommand`，准备过程直接显示原状态与进度；空库显示新建引导。主页完整实例集合独立于管理页搜索/分组/收藏筛选，以免常用实例被隐藏。
- 紧凑实例行显示真实封面/类型、名称、版本与加载器，可直接启动或管理；操作菜单复用模组管理、打开目录、导出备份、副本编辑器和删除确认。列表为覆盖式滚动条预留点击空间，避免遮挡行内操作。
- 六个快捷入口复用新建、导入、模组、资源包目录、游戏目录、诊断/日志能力；无实例时模组入口进入下载中心，目录类操作禁用。
- 联机卡使用真实组件安装和会话状态。只读 `LastPingMs` 来自已有游戏连接状态查询，更换目标、查询失败和断开时清空；未测显示“未测速”，不为首页额外发起扫描或测速。代理摘要依据本次运行实际配置，保存但尚未重启的新配置不会冒充已生效；下载源即时同步。
- 七段首次入场顺序为：标题栏页标、横幅、快速启动、联机状态、实例管理、快捷功能、辅助底栏，复用 220ms / 40ms 调度；启动入口始终可交互，减少动画和离开页面可立即归位，返回缓存首页不重播。

`--home` 通过 46 项检查，`--home-native` 在真实 Windows 窗口通过 15 项，联机页面另通过 31 项回归。1366×768 至少显示 5 条、1440×900 至少显示 8 条完整实例，六个快捷入口和底栏均可见；760×620 验证可滚动且无横向溢出。截图与启动链路检查使用隔离的离线测试数据和进程适配器；原生验收验证窗口、布局和动画，不表示已运行真实 Minecraft 联机对局。

本批共 1447 项编号检查，另通过架构约束、裁剪程序集回归和单文件启动。当前原生环境为 Windows 100% 系统缩放，其他 DPI、Windows 10、跨平台与真实游戏运行仍留待 M9。下一阶段为 M7 全局组件。


## preview.12：M7 全局组件

- 统一按钮八态：120ms 悬停、85ms 按下、140ms 松开，2px 键盘焦点环与瞬时 0.45 禁用态；异步命令执行中显示加载图标并阻止重复操作。
- 成功与失败图标接入联机业务确认结果，不把异步命令结束直接当作成功；失败保留重试入口。
- 四类模态弹窗统一使用 180ms 遮罩淡入、220ms 缩放与位移入场、150ms 退场；完成退场后才移除遮罩，支持快速反向、焦点恢复和减少动画。
- 原单条底栏提示升级为右下角最多四条通知，支持四种语义、单条关闭、动作与默认五秒自动淡出；任务结果和设置同步沿用原业务入口。
- Tooltip 统一 450ms 延迟与 140ms 淡入、4px 位移；关闭动画时立即呈现并清理过渡。
- 新增 29 项组件与 17 项 Windows 原生检查，覆盖真实异步防重入、业务反馈、弹窗中间帧、通知动作/队列/计时和 Tooltip。下一阶段为 M8 开发预览页。

按钮共用 primary / secondary / ghost / icon / danger-solid 模板，加载态跟踪 IAsyncRelayCommand.IsRunning；成功/失败由实际业务状态单独提供。加载图标停止旋转后仍保留可辨认的静态形状。安装、创建、加入三个反馈只归属对应动作，不借用扫描、检测或其他任务的结果。

AnimatedDialog 为安装向导、账号、确认和迁移后重启提供独立遮罩与主体动画。首次加载在 Loaded 后开始计时，避免初始化消耗动画时长；连续切换以最新版本为准，关闭后恢复焦点，Tab 在模态层循环。主体圆角 16px、中心缩放 0.97→1、Y 6→0；关闭等待 150ms 后才解除宿主输入拦截。中途关闭动画和卸载清理取消源及过渡。

ToastManager 保留 ShowNotice 调用兼容性，并在已知业务结果处提供语义。最多四条，超出淘汰最早条目；每条拥有可取消的五秒计时、独立关闭和一次性动作。右下角 20px、ZIndex 30；图标、标题与语义色同时区分 Info / Success / Warning / Error，长文字可查看完整提示。窗口关闭释放计时与偏好订阅。原普通状态栏仍显示运行状态。

`--components` 通过 29 项检查，`--components-native` 通过 17 项；同时回归首页、联机、页面、侧栏、标题栏、完整桌面、空库和旧主题迁移。合计 1493 项编号检查，另通过架构约束、裁剪程序集回归和生产单文件启动。默认五秒计时及真实透明度/缩放/位移中间帧由 Windows 消息循环验收。截图使用隔离离线数据；当前原生验证为 Windows 100% 系统缩放，其他环境与真实游戏仍留待 M9。下一阶段为 M8。


## preview.13：M8 开发预览页

- 新增 M8 开发预览页，集中检视按钮八态、五种变体、双主题与跟随系统、Tooltip、弹窗、四态通知、卡片和七段交错入场。
- 仅在启动进程设置 `FANGYU_DEV_SHOWCASE=1` 时显示“UI 预览 (Dev)”与注册 `Ctrl+Shift+D`；普通模式不挂载页面，命令与快捷键不能进入。
- 主题、动效和 240/72px 侧栏直接联动现有外壳，预览导航使用共享选中胶囊和指示条。
- 演示使用独立通知队列、弹窗和可取消的模拟异步命令；成功/失败反馈仅表示演示结果，不调用游戏、安装、账号或联机服务。
- 七段交错动效支持重播、快速重播与中途减少动画；离页清理模拟操作、通知和弹窗，缓存页面保留滚动与输入。
- 新增普通模式/无效开关各 7 项门控检查、35 项预览界面检查和 12 项 Windows 原生检查。下一阶段为 M9 最终验收。

独立 `UiShowcaseView` 和 `UiShowcaseViewModel` 通过 `MainViewModel` 导航进入并由窗口懒加载缓存。门控只读取进程环境变量的精确值 `1`，不持久化；普通模式隐藏入口、不注册快捷键，即使直接执行命令或修改显示开关也不能挂载页面。开发导航位于业务导航下方，复用 190ms 共享胶囊与指示条，紧凑态保留图标及 Tooltip。

八态样本直接复用生产按钮模板，悬停/按下/焦点样本固定真实伪类；可交互按钮另可检查真实鼠标和 Tab 状态。静态加载样本明确停用命令追踪，动态演示由实际异步 RelayCommand 驱动，取消与结果独立于业务状态。卡片、AnimatedDialog、ToastHost 和 Motion.PlayStaggerSequenceAsync 沿用既有组件；示例弹窗与通知限定于预览内容区。主题、侧栏、减少动画使用真实外壳偏好，开发演示不启动游戏、不安装内容、不扫描或连接联机。

七段预览重播先取消并等待旧序列归位，再启动最新序列，避免旧 finally 覆盖新动画；离页取消序列和模拟任务、清空示例队列并关闭弹窗，窗口关闭释放偏好订阅。返回缓存页保留滚动及输入。

`--showcase-disabled` 与 `--showcase-invalid` 各 7 项，`--showcase` 35 项，`--showcase-native` 12 项。另回归 M7 组件、主页、联机、页面、侧栏、标题栏、完整桌面、空库和旧主题；合计 1554 项编号检查，架构约束、裁剪程序集及单文件启动另行通过。当前原生环境为 Windows 100% 系统缩放，其他 DPI、Windows 10、跨平台与真实游戏运行留待 M9。启用和走查方法见 `mc-launcher/docs/ui-showcase.md`。
